# Issue Tracker

## Primary trackers

This repo uses **two complementary trackers**:

### 1. Local Markdown (`.scratch/`)

Agent-managed tasks, in-progress investigations, and scratch work live under `.scratch/<topic>/`.

- **Create**: Write a new `.md` file under `.scratch/<feature>/`.
- **List**: `ls .scratch/` or read the files directly.
- **Close**: Mark the file with `## Status: Done` or delete it.

Use this for AFK-agent tasks generated by `/to-issues`, investigation notes from `/systematic-debugging`, and scratch plans.

### 2. GitHub Issues (`github.com/HassanAhmed238/pzone-portal`)

Shared bugs, external feature requests, and team-visible backlog live in GitHub Issues.

- **Create**: `gh issue create --title "..." --body "..."`
- **Read**: `gh issue view <number> --comments`
- **List open**: `gh issue list --state open --json number,title,body,labels`
- **Label**: `gh issue edit <number> --add-label "..."`
- **Close**: `gh issue close <number> --comment "..."`

## Pull requests as a triage surface

**PRs as a request surface: no.** External PRs are not currently a triage surface.

## When a skill says "publish to the issue tracker"

- For AFK-agent tasks → write to `.scratch/`.
- For team-visible bugs/features → create a GitHub issue.

## When a skill says "fetch the relevant ticket"

Check `.scratch/` first; fall back to `gh issue view <number>`.
